= Features
:description: Progressive disclosure, TUI, locales, and line budgets.

* *Default Static Box Zoning* — Unicode-boxed panels compatible with pipes, redirects, and log files.
* *Opt-in TUI Viewport* — full-screen browser (`?:i` or `?:interactive`) with filter search and clipboard copy.
* *1-Line Integration API* — first-pass argument filtering into standard `main` entries.
* *Hierarchical Globbing (`*`)* — subtree extraction for scripts and agents (e.g. `tar ?:text operations *`).
* *Multilingual Localization* — OS locale auto-detection with overrides (`?:de`, `?:es,i`).
* *Sliding-scale Line Budgets* — strict screen boundaries (20-line Level 0 menu budget).
